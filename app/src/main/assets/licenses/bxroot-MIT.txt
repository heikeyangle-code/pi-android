bxroot — MIT License
====================

The APK redistributes five binaries from bxroot, an open-source container runtime
that this app offers as an optional engine (settings → 运行时加速（开源运行时 bxroot）):

  libbxroot.so               launcher/CLI — the file Android execve()s
  libbxroot-runtime.so       in-process hook (LD_PRELOAD semantics)
  libbxroot-linker.so        ELF interpreter for guest binaries
  libbxroot-bridge.so        host/guest bridge
  libbxroot-stub-loader.so   static/static-pie + execve routing loader

Upstream source: https://github.com/qiannianhuanxiang/bxroot
Pinned commit:   5c143864b0f36f42b79808547e39e57da688db68
The corresponding source for the binaries shipped in this APK is that commit of
that repository; the digests of the shipped bytes are in `runtime.lock.json`.

The five files above are used here unmodified.
