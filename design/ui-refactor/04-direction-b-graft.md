# 04 · 方向 B 的 Full pass 规格（v2）

用户选定方向 B，并授权「其他地方的优点也可以稍微移过来一丢丢」。本文件是 v2 的唯一增量规格；底座仍然是 `design-demos/direction-b.html`（已批准的那一版），其余一切以 `01-design-spec.md` + `brand-spec.md` + `00-screen-inventory.md` + `02-real-content.md` 为准。

## 1. 从 A 移过来的（一丢丢，只有两条）

1. **块脚耗时刻度**：每个工具块/命令块页脚右端加一条 **1px 竖/横刻度**，长度 ∝ `log₂(耗时毫秒)` 并按量级分段（<1s 一段、<10s 两段、≥10s 三段），颜色取状态色。目的是让 **132ms 与 6.4 秒一眼可比**。
   - **保留** B 原本的读数文字（`成功 · 132ms · 13 行`），刻度是它的视觉补充，不是替代。
2. **状态行补两个读数**：B 现有状态行是 `上下文 52% [分段进度] 104k / 200k $0.42`；在**同一行**补上 `输出 8.2k` 与 `缓存读 61.4k`（pi 的真实 usage 字段）。
   - ⚠️ **不做** A 的四格仪表盘、不做屏顶横读数带、不做等距立方、不做 12 格 bento。

## 2. 从 C 移过来的（一丢丢，只剩一条；第二条已被用户否掉）

1. **状态一律三重编码**：`字 + 符号 + 颜色`。任何只靠颜色表意的地方都要补上文字或符号（色盲与暗光可读）。适用于：工具卡状态、队列、审批、连接/引擎状态、错误。
2. **~~一屏只有一项用 accent~~ → 不做**（用户 2026-09-13：「不要做 C 的那个一屏幕一个什么了，那个不好维护」）。accent 按组件语义正常使用（主操作、选中态、链接、当前项），**不引入全局预算这条硬约束**。
3. **层级继续用 1px 线与表面阶梯，不用阴影**：这条与上面那条无关，保留——深色底上阴影本来就几乎看不见，而且耗性能。（B 原本的 inset hairline 保留。）

## 3. 明确不做

- A 的 12 格 bento、等距立方、屏顶四格读数带。
- C 的「零图标」（B 保留少量 18px 单线图标）。
- 任何渐变、模糊/毛玻璃、辉光、装饰动效、循环动画。
- 颜色一律 pi 令牌（`brand-spec.md` §2/§3），一个新色相都不许有。

## 4. v2 必须补齐的屏幕与状态（这是 Full pass 的重点）

hero 五台屏保留（对话 / 会话列表覆盖层 / 工作区 / 设置首页 / 设置分组页），但要**补齐同一屏的其余状态**，做法：hero 板保持 5 台不动，后面追加「状态册」若干组，每组横排 3-5 台同尺寸设备，逐台只改状态。

**对话**
- 块类型全覆盖：用户消息（含图片附件）、助手 markdown（标题/列表/行内码/码块/引用/表格）、`read`/`write`/`edit`+独立 `diff`/`grep`/`find`/`ls`/`bash`/`powershell` 工具卡、通用回退卡、思考块（折叠与展开）、时间分隔、压缩标记、分支摘要、模型切换、技能调用、扩展条目、错误块、提示条、图片网格。
- 状态：工具 **pending**（`运行中 · 已运行 12.3 秒 · 18 行`）、**成功**、**失败**（退出码 2）、**被拒**；流式中的助手文本（末尾光标）；`加载更早的 N 条`；`回到最新 · N`；搜索命中（当前命中 vs 其它命中）；队列（`穿插 N` / `后续 N` / `收回并编辑`）；审批弹层（允许/拒绝 + 倒计时 + `还有 N 个扩展对话框在排队`）。
- 空态两套（引擎启动中 / 引擎已就绪）+ 引擎失败态。

**会话列表覆盖层**
- 默认、搜索命中、两套空态（`还没有会话` / `没有匹配的会话`）、长按操作框（新建子会话/删除/取消）、删除确认（正常 + **当前会话禁止删除**）、排序与筛选的选中态、会话树视图（分支/分叉）。

**工作区**
- 项目现场默认态、空态（这个目录还没有 `.pi` 资源）、运行中有命令、git 改动为空的态。

**设置**
- 首页（含终端入口行）、搜索设置（命中高亮）、12 个分组里至少 5 个（模型与推理 / 消息与网络 / 外观 / 会话 / 运行时与诊断）、6 种行型、4 种生效徽标、危险行确认态、编辑器 sheet（选项 / 数字 / 文本 / 列表 / 主题）。
- App 专属子页各一张：设备能力、扩展包与项目信任、模型、凭证、许可、诊断。

**其他**
- ~~终端页（设置入口进入的全屏页）~~ —— **不做**。用户已明确「终端基本不用管它了，现在是个废品那个功能」：设置里保留那一行入口即可（顺手可达），不为它做任何界面或状态设计，不列进状态册（见 `03-navigation-decision.md` 的补充裁决）。
- Boot 三态（`准备启动本地引擎` / `正在安装运行时` / `引擎没有在运行`）。
- Snackbar 三档（info / warning / error + `知道了`）、扩展对话框（select / input / confirm / editor）。

## 5. 交付与自检

- 文件：`design-demos/direction-b-v2.html`（单文件、内联、不引用外部图片、pinned React 版本 + integrity）。
- **一个 `<script type="text/babel">` 块**（或每块用 IIFE 包住）——A 就是死在这条上的：多块共享全局作用域，同名顶层 `const` 直接白屏。
- 自检（写进文件末尾注释并逐条打勾）：正文 ≥14px / 标签 ≥12px / 对比度 ≥4.5:1；颜色全在令牌内；可见文本零路径零 `§`（机器内容区里的 pi 真实输出除外）；状态三重编码；`pageerror` 为 0；每台设备内导航可切、卡片可展开、sheet 可弹。
