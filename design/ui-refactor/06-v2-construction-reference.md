## 4. 状态三重编码（字 + 符号 + 颜色）逐类写法

| 场景 | 写法 |
|---|---|
| 工具卡 | pending `…`「运行中」warning；success `✓`「成功」success；error `✗`「失败」error；**被拒** `⊘`「被拒」`#9E9E9E`（被拒不是失败，不用 error 色）。页脚**永远同时有符号与状态词**。 |
| 引擎状态行 | `✓ 就绪` success｜`… 工作中` warning｜`◌ 启动中` warning｜`≡ 排队中` warning｜`✗ 引擎已退出` error｜`■ 引擎已停止` error；busy 动词（读取会话树等）用 `…` warning |
| 队列 | `⇢` 穿插 N（符号 warning，字与数字正文色）；`⇣` 后续 N（符号 muted）；不可用时整条 dim |
| 审批 | `!`「待决策」warning + 倒计时段 |
| 错误块 | `✗` +「出错了」error + 展开「详情」 |
| 开关行 | 控件 + `✓ 开`（success）/`○ 关`（muted）+ 文字；颜色只是第三层 |
| Snackbar | Info `·`（卡片底 + 正文色）｜Warning `!`（info 底 + warning 字）｜Error `✗`（toolError 底 + error 字，且**必带**「知道了」） |
| 扩展/资源状态 | `✓ 已启用` success｜`◌ 需重启引擎`（error 或 warning 字）；审批记录 `✓ 已允许`｜`⊘ 已拒绝` |
| 会话行 | 「当前」徽章（accent 色块 + 文字）；「分支」「已命名」是第三行文字后缀，不用颜色 |
| 图形类 | 节点字形、diff 的减号与 `−5` 对比度按图形 3:1 达标，且**同一信息旁边另有正文色文字版本** |

## 5. 明确没做（实现方不要自行脑补）

- **终端页**：没做界面、没进状态册、没有键条/键盘/空态；只在设置首页留一行普通入口行（副行「需要终端的扩展在那边」）。输入区**没有**「终端」chip；溢出菜单**没有**「打开终端」。
- **没有** todo / 待办 / plan / 子代理块，也**没有任何复选方框**；清单语义只由助手正文的 markdown 列表承担。
- **没有** A 的 12 格 bento、等距立方、屏顶四格读数带、暖白配色。
- **没有**「一屏只有一项用 accent」（用户已撤销）；accent 按语义正常使用。
- **没有**渐变 / 模糊 / 毛玻璃 / 辉光 / 装饰性动效 / 循环动画 / 阴影；没有 emoji 当图标。
- **没有**外部图片；图片网格是占位格。
- edit 卡与 diff 卡**没有**合并；**没有**「没有响应」这类源码里不存在的文案。
- 设置只出了 5 个分组页（模型与推理 / 消息与网络 / 外观 / 会话 / 运行时与诊断）+ 搜索 + 危险行 + 5 类编辑器 + 6 张专属子页；**另外 7 个分组没出屏**（「上下文与压缩 / 重试与网络 / 工具 / 扩展与资源 / 终端与 Shell / 安全与信任 / 隐私与关于」）——行型规则通用，**照第 2 节的 Row 规格抄即可**。`终端与 Shell` 里 pi 侧的 `shellPath` / `shellCommandPrefix` / `npmCommand` 属 pi 配置，按普通行型处理。
- 工作区**没有**做 ≥600dp 的两栏（终端已废弃）。
- 单台设备内的滚动位置是静态的（原型不滚到锚点），不是设计缺失。

## 6. 每台可交互的动作（原型里能点出来的状态）
