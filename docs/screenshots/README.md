# 截图目录

主 `README.md` 的「截图」一节引用这里的 6 个文件。**文件名固定**，换图请沿用同名：

| 文件 | 该拍什么 |
|---|---|
| `01-chat-tool-cards.png` | 对话页：流式输出 + 至少一张工具卡 |
| `02-tool-cards.png` | 工具卡细节：命令 / 读 / 改 / 搜索 任选几类同屏 |
| `03-theme-a.png` | 一个主题下的对话页 |
| `04-theme-b.png` | 另一个主题（同一个界面，方便对比配色） |
| `05-theme-c.png` | 第三个主题 |
| `06-surfaces.png` | 设置 / 工作区 / 终端 任选一屏 |

## 这些图的来路

界面上的**全部主题**都是这个软件自己按 pi 的主题令牌写出来的（`~/.pi/agent/themes/*.json`），
不是外部素材；截图也请只放本应用自己的界面，不要混入设计稿或第三方应用。
